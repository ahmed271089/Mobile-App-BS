# 🌓 Guide du Mode Sombre - Best Solving

## Comment Activer le Mode Sombre

### Méthode 1 : Depuis l'Application

1. **Ouvrez l'application** Best Solving
2. Allez dans l'onglet **Profile** (en bas à droite)
3. Descendez jusqu'à la section **Appearance**
4. Vous verrez 3 options :
   - ☀️ **Light** - Mode clair (fond blanc)
   - 🌙 **Dark** - Mode sombre (fond noir)
   - 📱 **System** - Suit les paramètres de votre téléphone

5. **Appuyez** sur l'option de votre choix
6. L'interface change **immédiatement** !

### Méthode 2 : Mode Automatique (Recommandé)

1. Allez dans **Profile** > **Appearance**
2. Sélectionnez **System**
3. L'application suivra automatiquement les paramètres de votre téléphone
4. Le mode changera selon l'heure ou vos réglages iOS/Android

## 🎨 À Quoi Ressemble le Mode Sombre ?

### Mode Clair (Light)
- Fond principal : Blanc (#FFFFFF)
- Cartes : Gris très clair
- Texte : Noir/Gris foncé
- Parfait pour : Utilisation en journée, extérieur

### Mode Sombre (Dark)
- Fond principal : Noir profond (#0A0A0B)
- Cartes : Gris sombre (#1C1C1E)
- Texte : Blanc/Gris clair
- Parfait pour : Utilisation nocturne, économie de batterie (OLED)

## 💡 Astuces

### Économie de Batterie
- Sur les téléphones avec écran **OLED** (iPhone X+, Samsung Galaxy, etc.)
- Le mode sombre peut économiser jusqu'à **30% de batterie** !
- Les pixels noirs sont éteints sur OLED

### Confort Visuel
- **Mode sombre** : Réduit la fatigue oculaire en soirée
- **Mode clair** : Meilleure lisibilité en plein jour
- **Mode System** : Le meilleur des deux mondes !

### Persistance
- Votre choix est **sauvegardé automatiquement**
- Même après fermeture de l'application
- Fonctionne hors ligne

## 🔧 Dépannage

### Le Mode ne Change Pas
1. Fermez complètement l'application
2. Redémarrez-la
3. Vérifiez dans Profile > Appearance

### Couleurs Bizarres
1. Assurez-vous d'avoir la **dernière version** de l'app
2. Essayez de changer de mode puis de revenir
3. Redémarrez l'application

### Mode System ne Fonctionne Pas
1. Vérifiez les paramètres de votre téléphone :
   - **iPhone** : Réglages > Luminosité et affichage > Thème
   - **Android** : Paramètres > Affichage > Thème sombre
2. Activez le mode automatique sur votre téléphone
3. Dans l'app, sélectionnez **System** dans Appearance
